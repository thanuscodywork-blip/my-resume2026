# Practical Exercise: Build Your Online Resume

Suggested duration: 2–3 hours. Level: beginner.

## Your task
Turn the starter files into a personal, single-page resume using HTML and CSS only. Complete the TODO comments and choose your own colours and typography. JavaScript, templates and CSS frameworks are not required.

## Learning goals
- Organise a page using semantic HTML.
- Use headings, paragraphs, lists and hyperlinks.
- Connect an external stylesheet and use class selectors.
- Apply the CSS box model, typography, colour and Flexbox.
- Adapt a layout for a narrow screen.

## Getting started
1. Extract the ZIP into a folder called student-name-resume.
2. Open the folder in VS Code or another text editor.
3. Open index.html in a browser. The starter already contains basic styling.
4. Keep index.html and style.css in the same folder.
5. Save your changes, then refresh the browser to see them.

## Part A — HTML content
Complete TODO 1–8 in index.html:
- Update the browser title, name and career interest.
- Write an About Me paragraph of 3–4 sentences.
- Add your programme, institution, study dates and two relevant subjects.
- List at least five skills with honest proficiency levels.
- Include two projects. For each, state its title, purpose, your role and tools used.
- Include an email link and a real portfolio or project link.
- Update the footer with your name.
- Keep the navigation links working with matching section IDs.

A circular profile photo placeholder is included. To replace it, save your photo as images/profile.jpg, change the image src in index.html to images/profile.jpg and update its alt text (for example, Portrait of Your Name). If you prefer another filename, update the src to match. Use your own or permitted images. Share only contact details you are comfortable displaying; a home address and identity number are not needed. Do not invent qualifications or work experience. Coursework and personal projects are acceptable.

## Part B — CSS styling
Complete TODO A–J in style.css:
- Set the name heading size and style the navigation.
- Add visible hover and keyboard-focus feedback.
- Apply section spacing, rounded corners and a subtle shadow.
- Style section headings and content links.
- Arrange project cards using Flexbox with wrapping.
- Style the footer.
- Use the supplied media query to adjust the header for screens up to 600px wide.
- Personalise the colours while keeping text readable.

## Part C — Check your work
- Open the page in a browser and confirm the stylesheet loads.
- Click every navigation, email and portfolio link.
- Use the Tab key: each link should have a visible focus indicator.
- Check a wide screen and a narrow screen around 375px wide.
- Confirm that text fits without horizontal scrolling.
- Check heading order: one h1, section h2 headings and project h3 headings.
- Remove all TODO text and comments after completing the exercise.
- Explain one HTML choice and one CSS choice to your lecturer.

## Submission
Submit a ZIP containing index.html, style.css and any images used, plus two screenshots showing the desktop and mobile layouts. Name it StudentID_Name_Resume.zip. No online hosting is required for this exercise.
